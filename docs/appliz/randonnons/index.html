📋 Nouveautés v1.0.0

Première version publique de Randonnons. • Enregistrement GPS continu via Foreground Service (écran éteint ✓) • Affichage carte hors-ligne depuis fichiers MBTiles (compatibles ign2mbt) • Stats en temps réel : distance, durée, vitesse, altitude, dénivelé +/- • Profil altimétrique interactif (MPAndroidChart) • Gestion des waypoints : ajout, édition, suppression • Import et export GPX et KML • Bibliothèque des traces et routes importées • Gestion des cartes MBTiles dans les réglages • Notification persistante pendant l'enregistrement
→ Toutes les versions sur GitHub

📲 Installation

  1. 1 Téléchargez l'APK avec le bouton ci-dessus
  2. 2 Ouvrez le fichier randonnons-v1.0.0.apk sur votre Android
  3. 3 Autorisez l'installation depuis cette source si demandé
  4. 4 Lancez Randonnons et accordez les permissions GPS
  5. 5 Dans Réglages → Cartes hors-ligne, importez vos fichiers .mbtiles générés par ign2mbt
